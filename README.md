## Overview
This is a responsive e-commerce website for a flower shop named "Flower." The website showcases various flower products, 
provides information about the company, displays customer reviews, and includes a contact form for inquiries.

## Features
- **Responsive Design**: Works on mobile, tablet, and desktop devices
- **Navigation**: Easy-to-use menu with sections for Home, About, Products, Reviews, and Contact
- **Product Showcase**: Displays flower pots with discounts and pricing
- **Customer Reviews**: Testimonials from satisfied customers
- **Contact Form**: Allows users to send messages directly
- **Footer**: Contains quick links, location information, and contact details

## Technologies Used
- HTML5
- CSS3 (via external stylesheet `style.css`)
- Font Awesome (for icons)
- Responsive design principles

## File Structure
```
index.html        - Main website file
css/style.css     - Stylesheet for the website
image/            - Folder containing all images and icons
b.mp4             - Background video for the About section
```

## How to Use
1. Clone or download the repository
2. Open `index.html` in any modern web browser
3. Navigate through the website using the menu or scroll

## Sections
1. **Home**: Introduction to the flower shop
2. **About**: Information about the company with a background video
3. **Products**: Showcase of flower pots with prices and discounts
4. **Review**: Customer testimonials with star ratings
5. **Contact**: Form to send messages to the shop
